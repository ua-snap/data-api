CUSP: CommUnity near-Surface Permafrost Observations

CUSP combines individual field observations related to near-surface permafrost, active-layer thickness, thaw depth, and related measurements. It is an observation-evidence dataset, not a continuous permafrost map. For complete documentation, see the GitHub repo etc. etc.

Service endpoint

Query observations within a 0.5° by 0.5° (TBD) WGS84 box centered on a latitude/longitude point. The service returns at most XYZ nearby records. When more records match, GeoJSON's numberMatched value reports the full match count and numberReturned reports the records included in the response. ????

Endpoint Example URL
Nearby CUSP observation point query /cusp/point/65.0628/-146.1627
Append ?format=csv to download the same records as a flat CSV file. CSV includes explicit WGS84 longitude and latitude columns.

Output

JSON output is a GeoJSON FeatureCollection. Each feature has a point geometry and published CUSP properties including cusp_obs_id, source, site_id, observation_date, method and permafrost-observation labels, depth values in centimeters, quality flags, and the source release_version.

CUSP: CommUnity near-Surface Permafrost Observations

CUSP combines individual field observations of near-surface permafrost, active-layer thickness, thaw depth, and related measurements. Each returned feature is source observation evidence at a point; it is not a continuous permafrost map or a modeled prediction.

This endpoint exposes the CUSP observation resource as GeoJSON and adds the source bibliography entry directly to every record as citation. For the canonical release-table contract, method codes, and quality-flag definitions, consult the CUSP data schema. The CUSP attribution guidance explains how to cite CUSP, its release, and the original data sources.

Service endpoint

Query observations in a 0.5° by 0.5° WGS84 (EPSG:4326) bounding box centered on a latitude/longitude point. In other words, the box extends 0.25° north, south, east, and west of the supplied coordinate. The service returns every matching record. The GeoJSON's numberMatched and numberReturned fields report the match and returned-record counts.

Endpoint Example URL
Nearby CUSP observation point query /cusp/point/65.0461/-146.0673
Append ?format=csv to download the same records as a flat CSV file. CSV includes explicit WGS84 longitude and latitude columns, the record-level citation column, and a quality_flag_descriptions column.

Path and query parameters

Parameter Required Description
latitude Yes WGS84 latitude in decimal degrees, from -90 through 90.
longitude Yes WGS84 longitude in decimal degrees, from -180 through 180.
format No Set to csv for a flat CSV download. Omit it for GeoJSON; no other query parameters or output formats are supported.

Malformed or out-of-range coordinates return HTTP 400. Unsupported query parameters or values return HTTP 422. If the upstream CUSP service cannot be reached, the endpoint returns HTTP 502.

Output

JSON output is a GeoJSON FeatureCollection. Every feature has a WGS84 point geometry, CUSP observation properties, human-readable labels, a source-level citation, and a top-level quality_flag_definitions lookup keyed by CUSP flag code. GeoServer may also include a crs member identifying EPSG:4326.

GeoJSON fields

Field Type Description
geometry.coordinates array Point coordinates in [longitude, latitude] order, WGS84 decimal degrees.
cusp_obs_id string Deterministic opaque identifier for the canonical observation content.
source string Canonical CUSP source key.
citation string Bibliographic citation for the original source represented by the record.
site_id string or null Site or point identifier supplied by the original source.
observation_date YYYY-MM-DD string Observation date.
method, method_label string Controlled observation-method code and its human-readable label.
pf_observed, pf_observed_label integer, string Permafrost-presence indicator (1 or 0) and its human-readable label.
thaw_depth_cm, pf_depth_cm, obs_limit_cm number or null Thaw depth, depth to permafrost, and observation limit in centimeters below ground surface.
has_thaw_depth, has_pf_depth, has_obs_limit boolean Whether the corresponding depth or observation-limit value is available for that record.
quality_flags string or null Semicolon-delimited CUSP quality-flag codes; blank or null means no current flag applies.
quality_flag_definitions object Top-level lookup from each CUSP quality-flag code to its category and descriptive text.
release_version string CUSP release version represented by the resource record.

A value of pf_observed: 0 normally means permafrost was not observed down to the positive obs_limit_cm; it does not mean permafrost is absent at all depths. Null depth values mean the corresponding measurement was not reported or could not be determined. See the CUSP data schema for the complete canonical-field definitions and caveats.

Citation and attribution

The API repeats the original-source bibliography text in each feature's citation field and in each CSV row. This makes it possible to retain provenance after filtering records, but it does not replace the full attribution requirements: analyses should cite CUSP itself, the exact CUSP release, and every original source represented by the records used. When multiple records use the same source, deduplicate that source's citation in the final bibliography.

CSV output

Append ?format=csv to the point URL to download the same returned records in a flat table. The CSV replaces GeoJSON geometry with longitude and latitude columns and preserves all published observation fields, including citation. Text citations are CSV-escaped when necessary, so they can contain commas and URLs without changing the column layout.

{% extends 'documentation/dataset_base.html' %} {% block title %}CUSP: CommUnity near-Surface Permafrost Observations{% endblock %} {% block intro %}

This endpoint provides access to individual field observations of near-surface permafrost, active-layer thickness, thaw depth, and related measurements compiled by the CUSP data synthesis project. Each record includes an observation location, date, method, and source citation. Coverage depends on where observations were collected.

Links to the dataset documentation and attribution guidance are included in the source data and references section below.

{% endblock %} {% block variables %}

Below is the list of variables returned for each observation under its properties key. Depth values are reported in centimeters below ground surface. Retain the accompanying method and quality flags for source-specific measurement caveats.

ID Description Units
pf_observed Permafrost-presence indicator: 1 for permafrost observed, 0 for permafrost not observed within the observation limit N/A
thaw_depth_cm Reported thaw depth cm
pf_depth_cm Depth to observed permafrost cm
obs_limit_cm Depth limit of the observation cm

Null depth values mean the corresponding measurement was not reported or could not be determined. A value of pf_observed: 0 normally means permafrost was not observed down to the positive obs_limit_cm; it does not establish absence at greater depths. See the CUSP data schema for the complete definitions and interpretation guidance.

{% endblock %} {% block endpoints %}

Point query

Query observations in a 0.5° by 0.5° WGS84 (EPSG:4326) bounding box centered on a point specified by latitude and longitude. The box extends 0.25° north, south, east, and west of the supplied coordinate. The service returns every matching observation at its recorded location.

Endpoint Example URL
Nearby CUSP observation point query /cusp/point/65.0461/-146.0673
CSV output is also available by appending ?format=csv to the URL.

Path and query parameters

Parameter Required Description
lat Yes WGS84 latitude in decimal degrees, from -90 through 90.
lon Yes WGS84 longitude in decimal degrees, from -180 through 180.
format No Set to csv for a flat CSV download. Omit it for GeoJSON; no other query parameters or output formats are supported.

A query with no matching observations returns HTTP 404. This indicates a lack of observation records in the search box. Malformed or out-of-range coordinates return HTTP 400. Unsupported query parameters or values return HTTP 422. If the upstream CUSP service cannot be reached or returns an unexpected response, the endpoint returns HTTP 502.

GeoJSON fields

Field Type Description
numberMatched, numberReturned integer Counts of matching and returned observations. Every match is returned.
geometry.coordinates array Point coordinates in [longitude, latitude] order, WGS84 decimal degrees.
cusp_obs_id string Deterministic opaque identifier for the canonical observation content.
source string Canonical CUSP source key.
citation string Bibliographic citation for the original source represented by the record.
site_id string or null Site or point identifier supplied by the original source.
observation_date YYYY-MM-DD string Observation date.
method, method_label string Controlled observation-method code and its human-readable label.
pf_observed, pf_observed_label integer, string Permafrost-presence indicator (1 or 0) and its human-readable label.
thaw_depth_cm, pf_depth_cm, obs_limit_cm number or null Thaw depth, depth to permafrost, and observation limit in centimeters; see the available variables table above.
has_thaw_depth, has_pf_depth, has_obs_limit boolean Whether the corresponding depth or observation-limit value is available for that record.
quality_flags string or null Semicolon-delimited CUSP quality-flag codes; blank or null means no current flag applies.
quality_flag_definitions object Top-level lookup from each CUSP quality-flag code to its category and descriptive text.
release_version string CUSP release version represented by the resource record.

CSV output

Append ?format=csv to the point URL to download the same returned records in a flat table. The CSV replaces GeoJSON geometry with longitude and latitude columns and preserves all published observation fields, including citation. A quality_flag_descriptions column provides readable definitions for each record's flags. Text citations are CSV-escaped when necessary, so they can contain commas and URLs without changing the column layout.

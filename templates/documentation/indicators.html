These endpoints provide access to yearly CMIP6 climate indicators and era-based summaries of the NCAR 12km climate indicators. The eras for this dataset are historical (1950–2009), mid–century (2040–2069), and late–century (2070–2099).

For more detailed information, see the links to academic references and source datasets included at the bottom of this page.

{% endblock %} {% block variables %}

Below is the list of climate indicators that are found in these endpoints.

ID Description Units
hd “Hot day” threshold — the highest observed daily maximum 2 m air temperature such that there are 5 other observations equal to or greater than this value °C
cd “Cold day” threshold — the lowest observed daily minimum 2 m air temperature such that there are 5 other observations equal to or less than this value °C
rx1day Maximum 1–day precipitation mm
su “Summer Days” — Annual number of days with maximum 2 m air temperature above 25 °C days
dw “Deep Winter days” — Annual number of days with minimum 2 m air temperature below -30 °C days
ftc “Freeze-thaw days” — Annual number of days with maximum 2 m air temperature above 0 °C and minimum 2 m air temperature at or below 0 °C (CMIP6 only) days
wsdi Warm Spell Duration Index — Annual count of occurrences of at least 5 consecutive days with daily mean 2 m air temperature above 90th percentile of historical values for the date count
csdi Cold Spell Duration Index — Same as WSDI, but for daily mean 2 m air temperature below 10th percentile count
rx5day Maximum 5–day precipitation mm
r10mm Number of days with precipitation > 10 mm days
cwd Consecutive wet days — number of the most consecutive days with precipitation > 1 mm days
cdd Consecutive dry days — number of the most consecutive days with precipitation < 1 mm days

CMIP6 climate indicator variables

Query CMIP6 climate indicator variables for all models and scenarios. These indicators are defined above.

Endpoint Example URL
Yearly climate indicator values at a given latitude and longitude. /indicators/cmip6/point/61.5/-147
Min/mean/max summaries of historical and projected data over 3 eras are available by appending ?summarize=mmm to the URL.
CSV output is also available by appending ?format=csv to the URL.

CMIP5 climate indicator variables

Query min-mean-max climate indicator variables for all models and scenarios. These indicators are defined above.

Endpoint Example URL
Era-based min-mean-max for all climate indicator variables at a given latitude and longitude. /indicators/cmip5/point/61.5/-147
Era-based min-mean-max for all climate indicator variables for a specific area /indicators/cmip5/area/1903040601
CSV output is also available by appending ?format=csv to the URL.

CMIP6 climate indicator variables

Results from point and area queries will look like this:

{
  ...
  "EC-Earth3-Veg": {
    "historical": {
      "1950": {
        "cd": -32.0,
        "cdd": 8.0,
        ...
        "su": 0.0,
        "wsdi": 0.0,
      },
      "1951": {
        "cd": -51.5,
        "cdd": 20.0,
        ...
        "su": 0.0,
        "wsdi": 0.0,
      },
      ...
    },
    ...
  },
  ...
}

The above output is structured like this:

{
  <model>: {
    <scenario>: {
      <year>: {
        "cd": "Cold day" threshold (°C) — the lowest observed daily minimum 2 m air temperature such that there are 5 other observations equal to or less than this value",
        "cdd": "Consecutive dry days" — number of the most consecutive days with precipitation < 1 mm",
        ...
        "su": "Summer Days" — Annual number of days with maximum 2 m air temperature above 25 °C",
        "wsdi": "Warm Spell Duration Index" — Annual count of occurrences of at least 5 consecutive days with daily mean 2 m air temperature above 90th percentile of historical values for the date",
      },
      ...
    },
    ...
  },
  ...
}

CMIP5 climate indicator variables

{
  "cd": {
    "historical": {
      "Daymet": {
        "historical": {
          "max": -30.3,
          "mean": -37.6,
          "min": -45.2
        }
      }
    },
    "longterm": {
      "MRI-CGCM3": {
        "rcp45": {
          "max": -21.9,
          "mean": -34.0,
          "min": -42.2
        },
        "rcp85": {
          "max": -27.2,
          "mean": -33.4,
          "min": -40.8
        }
      },
      ...
    },
    ...
  },
  ...
}

The above output is structured like this:

{
  <variable>: {
    <era>: {
      <model>: {
        <scenario>: {
          "max": <maximum annual indicator value over summary era>,
          "mean": <mean annual indicator value over summary era>,
          "min": <minimum annual indicator value over summary era>
        },
        ...
      },
      ...
    },
    ...
  },
  ...
}
